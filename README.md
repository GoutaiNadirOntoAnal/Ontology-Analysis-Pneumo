# Ontology-Analysis-Pneumo
The proposed project aims to implement an intelligent medical decision-support system specialized in the field of pulmonology. This solution seeks to transform unstructured medical information into organized, actionable knowledge, thereby facilitating its understanding and use within the diagnostic process.
يهدف المشروع المقترح إلى تطبيق نظام ذكي لدعم اتخاذ القرارات الطبية متخصص في مجال أمراض الرئة. ويهدف هذا الحل إلى تحويل المعلومات الطبية غير المنظمة إلى معرفة منظمة وقابلة للتطبيق، مما يسهل فهمها واستخدامها في عملية التشخيص.
